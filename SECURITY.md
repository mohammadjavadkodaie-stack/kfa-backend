# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately by email to `security@<DOMAIN-TO-BE-SET>`.
Do not open a public issue, and do not include sensitive details in a pull request or discussion.

Include as much of the following as you can:

- affected endpoint, version or commit
- reproduction steps or a minimal proof of concept
- impact you expect (data exposure, privilege escalation, denial of service, ...)
- any suggested fix

We aim to acknowledge every report within 3 business days and to keep you informed while we
investigate and fix it.

## Safe harbor

We will not pursue legal action or report you for research that stays within the scope above,
that avoids privacy violations, data destruction and service degradation, and that gives us a
reasonable chance to fix the issue before any public disclosure.

## Supported versions

Only the latest `main` branch is supported and receives security fixes. Older commits, forks and
local modifications are not.
